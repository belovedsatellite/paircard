# 페어 카드 스튜디오

중앙을 기준으로 좌우에 놓인 SIDE A / SIDE B 카드에 이미지와 글자를 넣고, PNG 또는 전환 효과가 들어간 GIF로 저장하는 도구입니다. 서버 없이 브라우저 안에서만 동작하며, 넣은 이미지는 어디에도 업로드되지 않습니다.

## GitHub Pages에 올리기

1. GitHub에서 새 저장소(repository)를 만듭니다. 무료 계정은 공개(Public) 저장소여야 Pages를 쓸 수 있습니다.
2. 압축을 푼 폴더 **안에 있는 파일과 폴더들**(`index.html`, `css`, `js`, `fonts`, `README.md`, `.nojekyll`)을 선택해 `Add file → Upload files`에 끌어다 놓습니다. 폴더 자체를 통째로 올리면 `index.html`이 한 단계 안쪽에 들어가 404가 뜹니다. 저장소 첫 화면에 `index.html`이 바로 보여야 합니다.
3. 저장소의 `Settings → Pages`에서 `Source`를 `Deploy from a branch`, 브랜치를 `main` / `(root)`로 고르고 저장합니다. 같은 화면의 `Enforce HTTPS`도 켜 두세요.
4. 1~2분 뒤 `https://<계정이름>.github.io/<저장소이름>/` 주소로 접속합니다.

### 새 버전으로 바꿀 때

저장소에서 `Add file → Upload files`로 새 파일들을 같은 위치에 다시 올리면 덮어써집니다. 바뀐 내용이 바로 안 보이면 브라우저에서 강력 새로고침(Ctrl+Shift+R / Cmd+Shift+R)을 해 주세요. 이전 버전에서 임시 저장된 작업은 그대로 이어서 열립니다.

올리지 않고 `index.html`을 더블클릭해 바로 열어도 동작합니다.

## 사용법

- **SIDE A / SIDE B 탭**: 카드를 추가하고 이미지·제목·짧은 문구를 넣습니다. 이미지는 눌러서 고르거나 끌어다 놓습니다.
- **미리보기 화면에서 직접 조정**: 카드 이미지나 배경 이미지를 끌면 위치, 마우스 휠을 굴리면 확대가 바뀝니다. 더블클릭하면 처음 상태로 돌아갑니다. 이미지 파일을 미리보기의 카드나 배경 위에 끌어다 놓으면 그 자리에 바로 들어갑니다.
- **배경 탭**: 단색·그라데이션·이미지(흐림 조절) 배경과 배경 큰 글자를 설정합니다. 큰 글자의 폰트(Google Fonts 포함)는 배경마다 따로 고를 수 있습니다. 배경을 여러 개 만들면 장면마다 다르게 쓸 수 있습니다.
- **스타일 탭**: 카드 글자 폰트(기본 Pretendard, Google Fonts 추가 가능), 카드 크기·색·글자 크기, 두 카드 사이 중앙 글자를 조정합니다.
- **타임라인(아래쪽)**: 장면 순서와 전환을 다룹니다.
  - `동시에 넘기기`: A와 B가 함께 다음 카드로 넘어갑니다.
  - `번갈아 넘기기`: A → B → A → B 순서로 한쪽씩 넘어갑니다.
  - `직접 구성`: 장면마다 어떤 카드와 배경을 보여 줄지 직접 고릅니다.
  - 장면을 누르면 그 장면의 전환 효과, 전환 시간, A·B 시간차, 유지 시간을 바꿀 수 있습니다.
  - 타임라인을 누르거나 끌면 전환 도중의 화면도 미리 볼 수 있습니다. 스페이스바로 재생/멈춤.
- **저장 탭**: 파일 이름 지정, PNG(지금 화면 / 모든 장면 ZIP), GIF, 작업 파일(.json) 저장·불러오기.
- **다크 / 라이트 모드**: 오른쪽 위 버튼으로 바꿉니다. 처음에는 컴퓨터의 설정을 따르고, 한 번 고르면 기억합니다.

입력 내용은 브라우저에 자동으로 임시 저장됩니다. 다른 기기로 옮기거나 오래 보관하려면 작업 파일로 저장하세요.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 뼈대, 보안 설정(CSP) |
| `js/theme.js` | 다크/라이트 모드를 화면이 뜨기 전에 적용 |
| `css/style.css` | 편집 화면(메뉴·타임라인)의 모양 |
| `js/render.js` | **템플릿 그리기** — 카드, 배경, 큰 글자, 전환 효과 |
| `js/export.js` | PNG / GIF / ZIP 내보내기 |
| `js/app.js` | 좌측 메뉴, 타임라인, 저장·불러오기 |
| `js/gifenc.js` | GIF 인코더 (외부 라이브러리) |
| `fonts/` | Pretendard 가변 폰트 |

### 템플릿 디자인을 고칠 때

- 카드 한 장의 생김새: `js/render.js`의 `drawCardContent()`
- 배경과 큰 글자: `js/render.js`의 `drawBackgroundInto()`
- 카드 위치(좌우 대칭 배치): `js/render.js`의 `CS.cardRects()`
- 전환 효과 추가·수정: `js/render.js`의 `CS.EFFECTS` 목록과 `drawCardTransition()`
- 각 설정의 기본값: `js/app.js`의 `DEFAULT_STYLE`, `newBg()`, `newScene()`

기준 캔버스는 1920×1080으로 고정이고, 저장할 때 배율만 바꿉니다.

## 알아 둘 점

- GIF는 한 프레임에 256색만 쓸 수 있어 PNG보다 색이 거칩니다. `색 띠 줄이기`를 켜면 부드러워지는 대신 용량이 1.5~2배로 늘어납니다.
- 뒤집기 효과는 원근감이 있는 3D 회전이 아니라 카드가 접혔다 펴지는 방식입니다.
- 움직이는 GIF를 카드에 넣으면 첫 장면만 쓰입니다.
- 한 변이 2400px을 넘는 이미지는 넣을 때 자동으로 줄입니다.
- Google Fonts는 인터넷 연결이 필요하며, 불러오지 못하면 Pretendard로 표시됩니다.

## 보안과 개인정보

- 모든 작업은 브라우저 안에서만 이뤄집니다. 넣은 이미지와 글자는 어떤 서버로도 보내지지 않습니다.
- 임시 저장은 그 브라우저의 저장소(IndexedDB)에만 남습니다. 공용 컴퓨터에서는 작업 후 `저장 → 모두 지우고 새로 만들기`로 지워 주세요.
- 외부 연결은 Google Fonts를 추가했을 때의 `fonts.googleapis.com` / `fonts.gstatic.com`뿐이며, 이때 사이트 주소(리퍼러)는 보내지 않습니다.
- `index.html`의 콘텐츠 보안 정책(CSP)이 이 사이트 파일과 Google Fonts 외의 스크립트·스타일·폰트를 막습니다.
- 작업 파일(.json)을 불러올 때는 숫자 범위, 색, 글자 길이, 이미지 형식(PNG·JPEG·WebP 등 비트맵만)을 검사해 이상한 값은 기본값으로 바꿉니다. 40MB가 넘는 이미지, 8000만 화소가 넘는 이미지, 300MB가 넘는 작업 파일은 받지 않습니다.
- **공개 저장소에는 사이트 파일만 올려 주세요.** 작업 파일(.json)이나 개인 이미지를 저장소에 올리면 누구나 볼 수 있습니다.
- GitHub Pages는 서버 응답 헤더를 바꿀 수 없어, 다른 사이트가 이 페이지를 액자(iframe)로 띄우는 것까지는 막지 못합니다. 로그인이나 개인정보가 없는 도구라 실질적인 위험은 없습니다.
